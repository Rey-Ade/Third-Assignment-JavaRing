# Project Title

A turn-based RPG inspired by Souls-like games which can be run in terminal

## Description

Java-Ring is a text-based role-playing game (RPG) that follows a structured combat system where players engage in
battles against powerful monsters. In this combat system, two sides - the player's and the enemy's side - attack
each other in turns until one is defeated.

### Mechanics:

* **Turn-based combat:** Players and monsters take turns attacking each other.
* **Character classes:** Players can choose from 3 different warrior archetypes: Knight, Assassin, or Wizard.
* **Monsters classes** : Players battle against Skeletons, Goblins or Dragons.
* **Damage system:** Each weapon deals a specific amount of damage, reducing the opponent’s health.
* **Defense system:** By choosing to defend, players can block or reduce incoming damage.
* **Reward system:** Players are rewarded with a consumable after defeating each enemy.
* **Repair system:** Before entering a battle, players can spend MP to repair their armor.
* **Battle to the death:** The combat continues until one side is completely defeated.

## Getting Started

### Dependencies

* Java 11 or later
* Gradle as a package manager

### Installing

* Fork this repository and clone it to your local machine:
```
git clone https://github.com/Rey-Ade/Third-Assignment-JavaRing
```

### Executing program

* Using an IDE or text editor:
  * Open Third-Assignment-JavaRing project
  * Navigate to Third-Assignment-JavaRing\Java-Ring\src\main\java\org\project
  * Run Main.java

## Help

* Ensure you have Java and Gradle installed
```
java --version
gradle -v
```
